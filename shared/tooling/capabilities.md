# 工具能力

任务实际需要文件、检索、计数或产物制作时完整读取，使用宿主真实可用能力。

<a id="tool-01"></a>
## TOOL-01 材料与规则定位

内容依赖文件时先读取必要范围，未知位置用搜索定位，已知位置直接扩展到连续上下文。遵守宿主的文件、连接器和权限规则，不猜测未见内容。
方法从当前角色入口寻找，共享标准从[能力索引](../INDEX.md)寻找；可用宿主查找，或运行[编号定位器](../../scripts/rules.py)：`python scripts/rules.py PROSE-07 --file`。首次加载读取全文，后续回查可以只取完整条款。

<a id="tool-02"></a>
## TOOL-02 资料研究与协作

需要事实核实、用户要求研究或现有材料不足时，依宿主规则使用可靠来源，执行[SRC-04](../standards/sources.md#src-04)。研究回答影响作品的未知，不变成自动添加外部例子的程序。
支持委派时，可按独立材料范围分工并交代问题、授权和返回依据。最终写作者统筹内容及意义，不自行增设多层审查和固定接力。

<a id="tool-03"></a>
## TOOL-03 篇幅统计

有长度要求且需要核对时，使用[统计工具](../../scripts/text_stats.py)：`python scripts/text_stats.py article.md --json`。工具分别统计汉字、其他文字数字词组与可见字符；用户有特定口径时以其口径为准。`--stop-before` 可按实际标题排除后续内容。
计数只回答篇幅问题，不能从句长、人称和关键词频率直接推断写作质量，也不执行统一风格自动替换。


<a id="tool-04"></a>
## TOOL-04 定位编辑、保存与交付

使用宿主已有编辑工具。读取最新基线后，以足够上下文唯一定位目标句段；重复文本需加邻接文字或结构位置，不作无范围的全局替换。只生成并写入目标区域及已确认依赖，其余文本直接沿用原稿。

完整文本可由原稿与替换片段组装。有文件工具时查看真实差异，确认未改区域保持；发现意外变化就恢复。目标内容与读取时不同则重新读取、合并用户更新后再编辑，不强行套用旧位置。批量术语或格式修改先明确适用区域，引用和专名按实际要求处理。

文档对象有结构化编辑能力时保留未改段落、表格和样式；只能转换重建时，检查受影响的文字与版式。纯聊天任务可按要求返回目标段落或复制未改原文组装全文。原稿不完整时先取得所需部分，无法取得就交付可完成的局部结果并说明缺口。

使用文件能力前读取宿主对应说明。文件真实生成后提供入口；外部发送、发布、覆盖与删除依用户授权。普通写作不新增自制补丁引擎、差异账本或审美评分器。
