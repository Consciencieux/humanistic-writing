# 组织与篇章推进

多段组织、结构重排、篇幅分配或调整完整作品时完整读取。

<a id="org-01"></a>
## ORG-01 选择推进关系

让读者按适合任务的顺序进入内容：可以依问题、理由、时间、空间、行动、视角、感受或意象推进。材料之间是什么关系，就选择能呈现这种关系的组织方法。
明确格式或栏目照要求使用；没有要求时，不自动配齐背景、意义、方法、建议和总结。结构服务内容，不把所有文字变成先概述后论证的同一框架。

<a id="org-02"></a>
## ORG-02 组织内容单元与主要展开位置

一个段落或单元承担可辨认的作用，复杂关系可以跨段展开，较小问题可以在句内解决。重要内容有主要展开位置，其他地方可引入、应用或必要回扣。
相同内容承担不同作用时可复现；没有推进的重述应合并或删除。不要按标题数量、段落长度、引文和例子的数量平均分配内容，也不故意制造参差。

<a id="org-03"></a>
## ORG-03 安排入口、承接与结束

入口使读者进入真正需要的对象、关系或情境。背景、经历、设问和场景都只是可选方式，按作用选择。承接补必要联系，能由内容自然接续时不再宣告。
结尾完成当前作品需要的收束：可以给出结果、行动、余韵或确切未解问题。不要把所有作品都结束为开放式追问、个人倡议或宏大升华。已有结论不再用另一段同义总结。

<a id="org-04"></a>
## ORG-04 选择呈现形式

标题帮助定位，列表呈现并列或步骤，表格支持同维度比较，连续文字展开关系。根据读者使用方式选择，不能只为版面整齐切成标签或短语。
导航、摘要、回顾和重复提示在长文或实际使用中可能必要，按功能保留。装饰性分节、过密小标题、无独立作用的栏目应调整。明确模板有实际约束时遵循。


<a id="org-05"></a>
## ORG-05 阅读负担与篇幅

篇幅分配依据内容重要性、读者已有知识和解释难度。判断长段时区分无作用重复、句法绕远、必要层次拥挤和内容偏离。必要层次可以拆段，重复可以合并；明显的字数要求需要实际精简。

取舍时保留决定理解的前提、区别、依据、推导与关键细节。例子可能使概括可理解，铺垫可能让情节变化成立；删后仍然通顺只回答了句法问题。摘要与用途转换按新读者需要取舍，事实与结论条件仍须准确。

按任务区分严格上限、最低字数、约数与页数，以用户规定的计数范围为准。[统计工具](../tooling/capabilities.md#tool-03)用于核对明确预算。预算冲突时指出具体无法兼顾的内容；未指定的删减比例不作为目标。扩写将空间用于尚需发展的内容，各部分详略随其作用分配。

<a id="org-06"></a>
## ORG-06 标题要定位内容，严禁装饰性钩子

普通讲稿、技术说明、课程报告和非虚构论述的标题首先要让读者知道这一节讨论什么。严禁为使每节“有记忆点”而批量写成“主题：金句／比喻／悬念／结论钩子”，严禁给所有标题机械套用对仗、数字口诀、戏剧化问句或预置立场。

标题可以直接写出真实主题，例如“油耗与旧车型兼容问题”，不必附加判断。重要结论确实是章节检索目标时可以成为标题，但不得把每节都改造成社论式断语。用户明确要求广告标语、文学标题或创意命名时按实际任务执行，仍不采用整套标题自动套模版。确认违规时恢复准确、便于导航的标题，不继续寻找另一组钩子。

<a id="org-07"></a>
## ORG-07 完整性与充实度分别判断

检查结构时区分“必要板块齐全”和“读者真正获得了内容”。段落每段都有主题、数据和总结，却没有说明关键关系，仍可能缺少实质内容；解决方法在[CONTENT-06](content.md#content-06)和[CONTENT-07](content.md#content-07)，不能靠增加栏目和结尾概括填充。

信息过密也可能是真实材料的必要细节，应按目标读者调整解释位置与信息顺序；某些部分简短、某些部分详细，可以是合适的篇幅分配。不得为了整齐平均缩减或扩充每个章节。
