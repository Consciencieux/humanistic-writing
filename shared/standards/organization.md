# 组织与篇章推进

多段组织、结构重排、篇幅分配或调整完整作品时完整读取。

<a id="org-01"></a>
## ORG-01 选择推进关系

让读者按适合任务的顺序进入内容：可以依问题、理由、时间、空间、行动、视角、感受或意象推进。材料之间是什么关系，就选择能呈现这种关系的组织方法。
明确格式或栏目照要求使用；没有要求时，不自动配齐背景、意义、方法、建议和总结。结构服务内容，不把所有文字变成先概述后论证的同一框架。

<a id="org-02"></a>
## ORG-02 组织内容单元与主要展开位置

一个段落或单元承担可辨认的作用，复杂关系可以跨段展开，较小问题可以在句内解决。重要内容有主要展开位置，其他地方可引入、应用或必要回扣。
相同内容承担不同作用时可复现；没有推进的重述应合并或删除。不要按标题数量、段落长度、引文和例子的数量平均分配内容，也不故意制造参差。

<a id="org-03"></a>
## ORG-03 安排入口、承接与结束

入口使读者进入真正需要的对象、关系或情境。背景、经历、设问和场景都只是可选方式，按作用选择。承接补必要联系，能由内容自然接续时不再宣告。
结尾完成当前作品需要的收束：可以给出结果、行动、余韵或确切未解问题。不要把所有作品都结束为开放式追问、个人倡议或宏大升华。已有结论不再用另一段同义总结。

<a id="org-04"></a>
## ORG-04 选择呈现形式

标题帮助定位，列表呈现并列或步骤，表格支持同维度比较，连续文字展开关系。根据读者使用方式选择，不能只为版面整齐切成标签或短语。
导航、摘要、回顾和重复提示在长文或实际使用中可能必要，按功能保留。装饰性分节、过密小标题、无独立作用的栏目应调整。明确模板有实际约束时遵循。

<a id="org-05"></a>
## ORG-05 阅读负担与篇幅

篇幅分配依据内容重要性、读者已有知识和解释难度。判断长段时区分无作用重复、句法绕远、必要层次拥挤和内容偏离。必要层次可以拆段，重复可以合并；明显的字数要求需要实际精简。

取舍时保留决定理解的前提、区别、依据、推导与关键细节。例子可能使概括可理解，铺垫可能让情节变化成立；删后仍然通顺只回答了句法问题。摘要与用途转换按新读者需要取舍，事实与结论条件仍须准确。

按任务区分严格上限、最低字数、约数与页数，以用户规定的计数范围为准。[统计工具](../tooling/capabilities.md#tool-03)用于核对明确预算。预算冲突时指出具体无法兼顾的内容；未指定的删减比例不作为目标。扩写将空间用于尚需发展的内容，各部分详略随其作用分配。

<a id="org-06"></a>
## ORG-06 文章题名与章节命名

先理解文章或章节实际完成的内容，再用自然、明确的名称标识它。标题保留最主要的对象、问题或关系，以及辨别范围必需的信息；解释、论据、次要议题和关键词清单留在正文。提炼时确定内容重心及关系，不能只挑出几个高频词重新拼接。

**主标题。** 命名全文的核心问题、对象或事件，覆盖实际重心。读书笔记可以点明所读作品与自己的具体问题，课程汇报和技术说明可以直接命名对象与主题。必要的副标题只补充文种、对象或范围，不承担再列一遍正文要点的任务。用户已确定的题名、引用作品的原题按授权保留；明确的叙事、文学或创意命名按相应作品目的选择，不将说明文题名强加给它们。

**小标题。** 命名本节独有的内容职责。上级标题已经明确的对象可以省略，兄弟小节仍需可区分。主题名称、实际回答的问题和正文已经支持的判断，依内容选择；不要求每节有观点、每节有问题或全部使用同一种词性结构。“引言”“结论”等正常栏目可直接保留。

采用汉语中准确、常见的词语搭配。专业名称在需要时保持完整；关系不清时先确定正文具体说明什么，再组织标题。不同内容允许不同详略，真正并列的章节可使用平行名称；无需刻意整齐，也无需为避免整齐而改坏已有名称。

**长度。** 普通中文小标题可优先尝试 4–12 个汉字；13–18 个字在必要信息明确时正常使用；超过 18 个字时回看是否混入解释、多个重心或重复概括。它们是编辑提示，不设最低字数、硬上限或违规分数。不得为凑短标题删掉关键对象、完整术语或必要范围。“方法”“结论”等短栏目照常使用。主标题、外语题名和固定格式按自身用途及明确要求处理，不套用小标题的字数参考。

内容定位准确、表达自然、层级清楚时完成命名。标题不承担展示材料丰富、文采或思想深度的任务。具体禁止行为集中在[ORG-08](#org-08)，据正文和当前任务判定。

<a id="org-07"></a>
## ORG-07 完整性与充实度分别判断

检查结构时区分“必要板块齐全”和“读者真正获得了内容”。段落每段都有主题、数据和总结，却没有说明关键关系，仍可能缺少实质内容；解决方法在[CONTENT-06](content.md#content-06)和[CONTENT-07](content.md#content-07)，不能靠增加栏目和结尾概括填充。

信息过密也可能是真实材料的必要细节，应按目标读者调整解释位置与信息顺序；某些部分简短、某些部分详细，可以是合适的篇幅分配。不得为了整齐平均缩减或扩充每个章节。

<a id="org-08"></a>
## ORG-08 标题生成与修订禁令

以下 14 项覆盖普通说明文、论述文章、读书笔记、课程汇报与技术文档的主标题和各级小标题。按实际文种、正文和授权确认；成立后必须修复。它们约束具体错误行为，不按疑问词、冒号、字数或标题相似度直接判错。

1. **严禁机械疑问化。** 不得把已有明确名称的章节批量转换为“为什么采用……”“……怎样做”“从……继承什么”等讲解提问。问题型标题须标识本节确实回答、值得作为检索入口的具体问题。
2. **严禁冒号式包装。** 不得套用“主题概括：抽象关键词清单”“A 和 B：关键词一、关键词二与关键词三”“A：为什么采用……”等骨架，重复概括、拼接讲解句或补上钩子。换成破折号、顿号等符号保留同一堆砌，仍须修复。正式副标题、用户规定格式与引用原题按各自实际作用处理。
3. **严禁强行对立与递进。** 不得为制造张力添加无内容依据的“从 A 到 B”“不是 A 而是 B”“在 A 与 B 之间”等关系，也不得将普通介绍排成认识、深化、超越的虚假进程。
4. **严禁文案化与标题钩子。** 普通文章标题不得附加金句、俏皮比喻、宣传口号、悬念、反问造势、强行升华及装饰性强调。删除此类加工后，不补写另一种表演性替代。
5. **严禁写作过程播报。** 不得将作者的讲解安排充当内容名称，如“从燃料本身出发，再进入具体问题”“先了解……再看……”。本节讨论的真实流程可以命名，作者准备怎样讲解不构成该流程。
6. **严禁模糊日常表达。** 不得用“应用中要注意什么”“全链条里其实也有信息”“关于……的一些思考”等泛泛说法掩盖没有确定的内容对象或关系。“其实”“也有”须有真实的预期或补充关系，不能为显得随和而添加。
7. **严禁关键词机械拼接。** 不得仅凭词语与主题相关，用“与、和、中的、里的”等将其并置。类似“五个环节里的计算机方法”的名称，须核实所指环节、方法及本节真实重心；缺少命名关系时回到内容重拟。
8. **严禁不自然的汉语结构。** 不得为概括或压缩省掉必要成分，形成动作归属不明、修饰关系错位或名词搭配别扭的标题。“发动机参数在仿真中筛选”一类表达应按本节具体操作恢复自然命名，不能只换介词。
9. **严禁抽象概念堆砌。** 不得以“价值、机制、路径、维度、能力、体系、挑战、启示”等泛化词替代实际对象、过程或问题。专业概念有明确所指时准确保留，不作禁词式删除。
10. **严禁机械数字分类。** 不得为制造层次凑出三重逻辑、四个维度、五条路径，或把正文偶然分成的段落数写成内容分类。真实、稳定且有检索作用的分类可以命名。
11. **严禁标题过度延长。** 不得为覆盖全文或整节而叠加所有论点、关键词、方法和次要限定。标题已能定位核心内容时停止补充；超长标题须从重心重新取舍，不能压成更短的概念串。
12. **严禁全篇标题同质化。** 不得为形式整齐给不同职责套用同一疑问、冒号、修辞或字数骨架；也不得为追求变化而改坏真实并列、模板规定或本来准确的名称。目录协调依据层级与内容关系。
13. **严禁无依据的判断与拔高。** 不得在标题中增加正文未支持的结论、比较、重要性宣告或宏大意义。真实未决问题保留其状态，已成立的具体判断保持相应强度。
14. **严禁标题与内容职责脱节。** 不得只凭文章主题、几个关键词或空提纲命名，掩盖章节缺乏重心或多个无关任务并存。主标题对照全文，小标题对照本节与上级标题；材料不足时仅依据已知内容提出范围相称的暂定名称，不补造正文或结论。

确认问题后回到[ORG-06](#org-06)重新确定命名对象。只改标题的任务保持正文不变；结构问题超出授权时指出位置，不借拟题重写全文。每项问题以具体含义、范围或阅读影响说明，不以命中模板的数量评定质量。
