# 构思与内容发展

需要决定写什么、从零构思、补充材料、扩写或改变内容重心时完整读取。

<a id="content-01"></a>
## CONTENT-01 确定表达重心

围绕目标选择真正值得展开的内容。重心可以是一项判断、一段变化、一种感受、一段关系或读者要完成的事，不必强行提炼为论文式论点。
宽泛主题先缩到可处理的对象与角度。用户已有思想链时理解其关系；授权原创时主动提出角度，避免停在同义改述题目。选择能支撑作品的重心，不为覆盖所有方面无限铺开。

<a id="content-02"></a>
## CONTENT-02 生成并筛选素材

按任务从已有材料、可核实事实、观察、推论或授权虚构中形成素材。构思阶段可以探索不同方向，成文选择真正参与表达的内容，不把全部备选方案都写进去。
素材是否具体、是否新近、是否带专业词，不能单独证明它有用。细节应改变理解、感觉或后续发展；只有完成要求的装饰作用时，可以不用。事实性材料按[SRC-01](sources.md#src-01)核实。

<a id="content-03"></a>
## CONTENT-03 把概括展开为可理解的内容

解释一个判断时说明它怎样成立；描写一个对象时选择有辨识力的细节；叙述变化时写出行动、反应与转折；表达感受时让情境或措辞承担感受。选择当前需要的展开方式，不给每段同时配齐解释、例子和感想。
具体化不能靠编造真实经历。授权虚构可创造事件与细节；真实材料不足时采用已知内容、明确的假设或必要查询。

<a id="content-04"></a>
## CONTENT-04 控制深度与信息分量

将篇幅用在当前读者最需要、最难理解或最有表现力的内容上。深度来自追踪关键关系、辨析重要区别、展开有作用的细节，不来自增加术语、设问或态度词。要求个人思考时，从材料中的具体疑点、差异或后果形成判断，并给出所需依据；“我开始思考”这类宣告自身没有补上分析。已有分析清楚充分时保留，尚缺材料时处理具体缺口，不代编作者的心理历程。
读者已经知道的背景可压缩；影响理解的前提需要交代。保留能推进作品的侧枝，删除没有回报的旁逸，不强求各部分展开到同一程度。

<a id="content-05"></a>
## CONTENT-05 补足内容而不替换目标

扩写应补真实缺口，压缩应保留表达的核心关系。发现没有足够内容支撑某段时，可重选素材、调整角度或删除该段，不能靠意义宣告和修辞填满。
已有文本的核心问题、人物关系或行动目的，不因补充内容而被旁观解说替代。改动实质方向时依当前授权执行，范围遵循[变更契约](../core.md#core-04)。

<a id="content-06"></a>
## CONTENT-06 建立解释的中间层

说明性段落先辨认读者已经掌握的起点和当前要理解的结果，再找出两者之间真正缺少的连接：定义、机制、条件、比较依据、计算、作用过程或具体后果。选用当前关系所需的连接，不要求每段都有完整的“结论—数据—金句”结构。

单有数据和结论却缺少连接时，补解释；已有解释只是拥挤时，调整组织；若数字、结论和材料互不支持，先核查或缩小主张。不能把“有三个理由”当作解释了三个理由，也不能用抽象评价和段末总结填补中间层。

例如，材料只说明“新增服务窗口后，办件量上升，等待时间未测量”。能够说明该时段办理量变化；读者若关心排队效率，就要明确等待时间缺失，不能把办件量增长直接换算为等待改善。这样的解释由证据关系决定，不能靠多添一段意义宣告完成。

<a id="content-07"></a>
## CONTENT-07 让术语和数据参与理解

使用专业词或数字前，先确定它在当前问题中承担什么：标识必要对象、定义测量指标、给出比较依据、说明变化或支持结论。判断读者需要知道的单位、条件、分母、基准和术语含义；专业读者已熟悉的概念无需逐个解释，跨专业读者尚无法理解的关键项应按其作用说明。

多项数值应服务同一个明确的观察或比较，区别不同指标，必要时说明数据能够支持到什么程度。若测量条件不同，先交代条件，再决定是否能比较。缺少条件时核实材料；无法核实就限制受影响的说法。不能把“列更多数字”视为严谨，也不能为了通俗直接删掉决定结论的数值和专业概念。
