# 判断、解释与推理

需要提出或检查理由、因果、比较、解释、论证与结论时完整读取。创作中不承担论证功能的段落，不逐句套用论点证明框架。

<a id="logic-01"></a>
## LOGIC-01 辨认主张及其依据

分清事实陈述、解释、预测和价值判断，并说明当前确实需要的依据。主题或态度词尚未形成具体判断时，把内容说清；不要用“体现了”包裹一个尚未完成的话题。
稳定关键概念的含义。概念有多种用法时在会影响推论处辨清，不为全面而给每个常用词下定义。

<a id="logic-02"></a>
## LOGIC-02 连接理由和结论

事实到评价、例子到概括、引文到解释、历史类比到现实判断，都要有适当的关系。相关性、时间先后或一条权威引文不能单独填补因果机制。
缺少一环时补出有依据的理由、收窄结论或指出确切未知。不能通过改换“因此、所以、由此可见”掩盖跳步。解释应让读者能够跟随实际推导。

<a id="logic-03"></a>
## LOGIC-03 保持范围与结论强度

区分可能、已经与必然，个人经验与群体事实，有利条件、必要条件与充分条件。依据能够支持多强的结论，就用相应表达，不默认弱化全部判断。
前后冲突回到定义、前提或事实负责的位置修正，并同步实际受影响内容。重要限定写入受影响命题，不沿全文附加泛泛防御性尾句。

<a id="logic-04"></a>
## LOGIC-04 处理比较、异议与选择

比较需要明确相关维度和条件。回应实际存在的主张，不创造一个更极端的版本供自己反驳。重要异议会改变判断时处理，不为结构完整给每段补一面相反观点。
做选择时明确决定性理由，允许有取舍。价值判断可以鲜明，解释一种行为的原因也不必转成对它的赞同。实际需要的区分才展开。

<a id="logic-05"></a>
## LOGIC-05 按求解程度结束

已有材料能回答的问题就回答；暂时解释说明成立条件；尚未解决的问题指出具体卡点。不要因追求闭环假装回答，也不要为了表现深刻保留虚假的困惑。
论述中的问题需要得到处理，叙事中的悬念则可按创作目标保留。是否闭合取决于当前作品的用途。对未来的不确定与对当前事实的明确判断可以同时存在。
