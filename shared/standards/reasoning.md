# 判断、解释与推理

需要提出或检查理由、因果、比较、解释、论证与结论时完整读取。创作中不承担论证功能的段落，不逐句套用论点证明框架。

<a id="logic-01"></a>
## LOGIC-01 辨认主张及其依据

分清事实陈述、解释、预测和价值判断，并说明当前确实需要的依据。主题或态度词尚未形成具体判断时，把内容说清；不要用“体现了”包裹一个尚未完成的话题。
稳定关键概念的含义。概念有多种用法时在会影响推论处辨清，不为全面而给每个常用词下定义。

<a id="logic-02"></a>
## LOGIC-02 连接理由和结论

事实到评价、例子到概括、引文到解释、历史类比到现实判断，都要有适当的关系。相关性、时间先后或一条权威引文不能单独填补因果机制。
缺少一环时补出有依据的理由、收窄结论或指出确切未知。不能通过改换“因此、所以、由此可见”掩盖跳步。解释应让读者能够跟随实际推导。

<a id="logic-03"></a>
## LOGIC-03 校准不确定性与结论强度

区分可能、已经与必然，个人经验与群体事实，有利条件、必要条件与充分条件。已确认的事实使用确定表达，有充分依据的评价直接下判断；不确定性只作用于真正未知的内容，不得为了降低出错风险叠用“可能”“在一定程度上”等概率限定，也不得用局部未知自动削弱整体结论。

严禁擅自扩大命题范围或自行提高证明标准，再以“尚无足够横向数据”宣告证据不足。重要限定直接写入受影响命题，不在结尾或句尾附加泛泛防御性声明。

<a id="logic-04"></a>
## LOGIC-04 回应真实主张，禁止虚构质疑与强迫平衡

比较需要明确相关维度和条件。只回应材料或讨论中真实存在的主张与异议，严禁为了显得客观、谨慎或有批判性，先虚构一个用户并未提出的极端观点或潜在误解再加以反驳或预防。

重要异议会改变判断时才处理，不为形式平衡给每段补一面相反观点。做选择时明确决定性理由，允许有取舍；价值判断可以鲜明，解释一种行为的原因也不必转成对它的赞同。

<a id="logic-05"></a>
## LOGIC-05 检验初始假设并按求解程度结束

分析前先核对实际需要解释的现象，根据解释力和证据选择主要假设；出现重要反例时重新检查初始前提，必要时推倒重排，不为维持表面一致继续维护失效框架。

已有材料能回答的问题直接回答；有成立条件时说明条件；尚未解决的问题指出具体卡点。不因追求闭环假装回答，也不为了显得深刻保留虚假的困惑。论述中的问题需要得到处理，叙事中的悬念则可按创作目标保留。
