# 表达位置、声音与语体

建立或保持叙述声音、处理人物与作者关系、表达个人立场、转换语域或视角时完整读取。

<a id="voice-01"></a>
## VOICE-01 确定谁在说、对谁说

辨认作者、叙述者、人物、引述来源和读者的位置，以及各自掌握的信息。不同声音可以共存，不能由一个全知的解释口吻覆盖。
人称、称谓、距离和态度随关系选择。读者需要辨别说话者时交代清楚；视角转换要有可追随的依据。第一人称没有固定配额，无人称也不天然更客观。

<a id="voice-02"></a>
## VOICE-02 形成适合任务的声音

依据读者、场合、媒介及用户选定的样稿，确定语气与语言强度。保留有作用的幽默、锋芒、温度、庄重或克制，不以统一中性替代全部声音。
风格通过选材、句法、节奏和距离共同形成。叙述、分析、引用和对话可以有不同的语气；协调时处理实际冲突，保留承担不同功能的差异。不要为了明显体现最新反馈，把全文刷成同一套口吻。不要把“学生、自然、专业、亲切”等标签机械转成词语清单，也不要在未获授权时模仿真实作者的个人经历。

<a id="voice-03"></a>
## VOICE-03 保持人物与叙述的连续性

在叙述和对话中维护人物已知信息、动机、行动和语言关系。时间、空间、视角与情绪变化要能被理解；有意跳切或不可靠叙述可以保留，不为解释完整破坏悬念。
角色可以误解、撒谎或自相矛盾，但作品需要让这种安排服务表达。不能把角色的话一概当成作者的事实陈述来纠正。

<a id="voice-04"></a>
## VOICE-04 处理真实作者与既有材料

编辑真实作者的文字时，保留其问题、判断和态度的归属。个人疑问改为“人们普遍关注”，既改变主体又可能增加无依据的群体事实；个人解释改成来源原意也会改变责任。
不替真实作者创造往事、情绪或顿悟。用户后来亲自写入或确认的内容，以最新稿为准；原先因缺乏依据不可代写，并不使同类句式永久禁用。

<a id="voice-05"></a>
## VOICE-05 按受众转换而保留必要内容

面向另一类读者时，调整预备知识、解释分量、称谓和表达方式。正式化可减少随意表达，口头化要照顾听众跟随，通俗化应解释术语而非删掉关键条件。
明确的全篇语域要求可以贯穿作品，但不同段落仍有不同作用。不因换语域擅自改变事实、承诺、立场或故事事件。转换范围遵循[变更契约](../core.md#core-04)。

<a id="voice-06"></a>
## VOICE-06 口头表达按听众理解与现场用途组织

口头汇报首先确保听众只听一遍也能把握对象、关键关系及下一步。按真实听众的已有知识安排必要概念；复杂数字交代比较口径与重点；一口气难以听懂的条件可以拆成相邻句，相关信息也可以保留完整长句。话题转换依靠内容的承接，无法自然衔接时补清关系。

用语可以比正式论文直接、句法可以更适于朗读，但不是把每段改成聊天、开场加假互动，或在技术事实后穿插固定的俏皮句。真正需要听众行动时明确说出要做什么；没有真实互动任务时直接陈述内容。表演性口语直接受[PROSE-09](prose.md#prose-09)约束。

<a id="voice-07"></a>
## VOICE-07 学术与正式风格由表达责任形成

学术和正式表达先保证对象、概念、范围、来源与结论强度准确。研究事实说明观察与条件，解释阐明理由，价值评价交代判断依据；根据文种和读者决定背景及引文分量。严谨允许直接、鲜明的结论，不靠被动句、第三人称、抽象名词或连续免责声明制造学术感。

论文、综述、课程报告、正式评论和读书笔记的作者责任不同。读书笔记的真实个人疑问可以保留，论文中的研究判断必须有依据，正式讲稿需要可听性。用户指定的格式与明确的引注要求仍照办；需要专业学术论文的章节和证据方法时使用专门技能，不将统一论文模板推广到全部非虚构作品。
