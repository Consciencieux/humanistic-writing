# 语言表达

实际生成或修改句段表达、审查语言时完整读取。先依据当前操作确定内容与目标，再按目标语言的语法、语用和表达习惯执行。以下能力用于判断实际句段；常规非虚构说明、论述和汇报中的表演性写法执行 PROSE-09～PROSE-12 的直接禁令。禁令针对写作行为及其用途，禁止换词继续实现同一行为。创作任务明确需要人物对白、喜剧或修辞实验时，在该任务的授权范围内处理。

<a id="prose-01"></a>
## PROSE-01 写清句子中的关系

让读者辨认当前需要的对象、动作、条件和相互关系。语法可以省略已知信息，标题、对话、字幕或有意的断句也可以简短；关键是读者能否在当前语境恢复其含义。
连续说明需要关系时，不用名词堆、斜杠和箭头替代解释。例如“需求增加／资源紧张／服务下降”尚未交代因果链，应按实际条件写清。若这些短语只是图中的标签，则不必扩成长句。

<a id="prose-02"></a>
## PROSE-02 选词准确，指称稳定

用能够指向实际对象和含义的词语。普通动作能表达清楚时直接写，概念或术语承担准确含义时保留并作必要解释。不要用“机制、赋能、价值”等抽象词填补尚未明确的内容，也不因追求朴素而删掉必要概念。
同一对象的称呼保持可辨认，不为避免字面重复不断换名。代词、简称和省略应有明确所指。引号和特别强调要有引用、命名或修辞上的作用。

<a id="prose-03"></a>
## PROSE-03 安排信息重点与句间承接

依据读者已经知道什么，安排新信息与解释。重要内容放在容易被理解的位置，修饰语贴近其对象，复杂条件不要无限堆在句尾。信息较密时拆分关系，信息连续时允许长句。
句间可以靠具体内容、必要关键词和指代承接，不必每句加连接词。“因此、然而、同样”等词必须对应真实关系；关系缺失时补足内容，不能仅换一个连接词。推导涉及实质判断时使用[LOGIC-02](reasoning.md#logic-02)。

<a id="prose-04"></a>
## PROSE-04 选择适合场合的语域

称谓、措辞、距离与态度要适合表达者、读者和场合。正式文字可以直接，亲切文字也需要内容清楚；口语表达要便于听懂和说出，不是在书面句尾添加语气词。
人称、情绪、礼貌和作者声音按功能使用。第一人称可能说明经验或解释归属，无人称也可能适合陈述；不按次数增删。需要建立声音、保持视角或转换语域时，加载[VOICE](voice.md)。

<a id="prose-05"></a>
## PROSE-05 用节奏承载内容

句长、停顿、段落和标点共同组织阅读节奏。连续动作、复杂解释、迟疑或强调需要不同速度，按内容调整，不以长短句比例判定自然。
简洁不能删掉必要关系；舒缓也不能靠同义复述填长。整齐、重复、碎片和跳切都可能有作用，只有遮蔽内容或破坏预期效果时才调整。不要为模拟真人故意制造错字、逻辑断裂或随机口语。

<a id="prose-06"></a>
## PROSE-06 让修辞产生具体效果

比喻、反问、排比、反复、对比等手段要服务理解、感受或记忆，不能代替事实和推理。比较双方应有可理解的关联，语气转折应有实际理由。
不预设每个判断都要补一个反面意见，每个段尾都要有金句。作者有意的锋芒、幽默、庄重和诗性可以保留；不把不同修辞全部清洗成中性说明。

<a id="prose-07"></a>
## PROSE-07 区分必要指引与空转播报

来源归属、篇章导航、作者解释和交际礼貌有时是必要内容。判断它们是否帮助读者辨认依据、位置、立场或关系，而非一概删除。
严禁用“这一点很重要、下面深入分析、体现了价值”等过程播报替代正在讨论的内容；没有独立导航或交流作用的句子应删除。重复播报同一来源、复述标题、证明完成制作要求，没有增加阅读价值时不保留。替换“指出”为“强调”不能解决空转。“有个人思考”“联系现实”等写作要求通过实际判断和材料关系落实，不改写成“这引发了我的思考”“结合当下社会”的任务回声。确有作用的第一人称和过渡仍按内容保留。

<a id="prose-08"></a>
## PROSE-08 用实际作用选择保留或修改

检查一句话是否完成了信息、解释、叙述、情绪、审美或交际作用。删除后仍然通顺，不意味着没有损失：可能丢失归属、态度、节奏或礼貌。反之，只剩话题而没有内容时，应补真实内容或删掉无必要段落。
用户提出“机械、松散、不自然”等评价时，对照实际文字判断原因，不把举例当成已经发生的缺陷。诊断按实际作用与[任务目标](../core.md#core-01)定位；词频和固定句式统计只可能提供线索，不能直接决定质量。保留、补充和调整都应服务当前位置的作用；不要把“每句都有价值”执行成每句必须增加新事实或作出新判断，必要的铺垫、停顿和余韵按作品目的保留。

<a id="prose-09"></a>
## PROSE-09 直接禁止表演性口语与假互动

在常规说明、课程汇报、正式发言和非虚构论述中，严禁为了显得口语化而添加主持人式串词、假互动、虚构听众反应、自我提示式口语和周期性活跃气氛的句子。

典型违规形态包括开场与转场无缘由地使用“先问个事儿”“咱们算笔账”“翻译成人话”“别急着鼓掌”“我随时奉陪”，或面向未实际发生互动的听众连续抛问。它们属于禁止主动生成的写法，不通过换成近义句、增加互动间隔或减少使用次数来规避。用户原文中的真实引语、已有的现场问答记录和明确要求分析的错误示例按材料性质处理。

删除这些表演性句子后，直接按内容承接；实际需要解释则解释，实际需要计算则计算。禁止再补一个“更自然的串词”填补位置。口头表达的正面能力由[VOICE-06](voice.md#voice-06)定义。

<a id="prose-10"></a>
## PROSE-10 直接禁止装饰性幽默、廉价比喻与金句

常规解释、汇报和论述中严禁主动插入以抖机灵、制造笑点、显得有态度或生成记忆点为目的的俏皮话、玩梗、口号、评论员式金句和装饰性比喻。尤其禁止把这些写法当作每节、每段或每个转场的固定配件。禁止用“更克制的俏皮话”替换已判定的装饰内容。

识别其作用：移去修辞后，原句是否只少了一层促销式包装，是否在技术数据、解释或结论之外另加不必要的情绪重音，是否打断了场合要求的语域。确认属于装饰性表演时直接删除；如果它遮住了缺失的事实或推理，则补写原本需要的内容。不得将这项禁令扩张为删除用户明确要求的虚构喜剧作品、真实引述或承担认知解释的必要专业类比。

<a id="prose-11"></a>
## PROSE-11 直接禁止装饰性引号与排版重音

严禁给普通问题、态度词、结论和所谓关键词批量添加双引号，借标点模拟口语重音、笑点、反讽或“作者在强调”。同样禁止通过装饰性加粗、斜体和无依据的强调符号让普通说明显得生动或专业。

真实引文、书名规范、已定义术语、引用对象的原话及目标格式规定的标记按其实际功能保留。对违规装饰，去掉标记、保留原有信息；不再换一种强调格式。口头重音通过句子的信息重点和自然停顿承载，不通过写给听众看的排版提示承载。

<a id="prose-12"></a>
## PROSE-12 直接禁止制造对立与批量修辞骨架

严禁为了制造转折、对仗或升华，先虚构一个原文没有、材料也不需要回应的观点，再通过“不是……而是……”“不在于……而在于……”等结构否定它。严禁把一组段落统一加工为相同的排比、二元对立、反问、解释和总结骨架。

已经存在的真实分歧、明确纠错、必要对比和作者选择的叙事复现按内容与关系处理，不按连接词出现次数判错。确认属于人为制造的对立时，删除虚构对象，直接表达当前事实或判断；确认属于全篇刷同一骨架时，按各部分真实职责恢复不同的展开方式。
