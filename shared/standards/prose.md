# 语言表达

实际生成或修改句段表达、审查语言时完整读取。先依据当前操作确定内容与目标，再按目标语言的语法、语用和表达习惯执行。以下能力适用于句段表达，具体手段由任务决定，不设统一口吻和词语黑名单。

<a id="prose-01"></a>
## PROSE-01 写清句子中的关系

让读者辨认当前需要的对象、动作、条件和相互关系。语法可以省略已知信息，标题、对话、字幕或有意的断句也可以简短；关键是读者能否在当前语境恢复其含义。
连续说明需要关系时，不用名词堆、斜杠和箭头替代解释。例如“需求增加／资源紧张／服务下降”尚未交代因果链，应按实际条件写清。若这些短语只是图中的标签，则不必扩成长句。

<a id="prose-02"></a>
## PROSE-02 选词准确，指称稳定

用能够指向实际对象和含义的词语。普通动作能表达清楚时直接写，概念或术语承担准确含义时保留并作必要解释。不要用“机制、赋能、价值”等抽象词填补尚未明确的内容，也不因追求朴素而删掉必要概念。
同一对象的称呼保持可辨认，不为避免字面重复不断换名。代词、简称和省略应有明确所指。引号和特别强调要有引用、命名或修辞上的作用。

<a id="prose-03"></a>
## PROSE-03 安排信息重点与句间承接

依据读者已经知道什么，安排新信息与解释。重要内容放在容易被理解的位置，修饰语贴近其对象，复杂条件不要无限堆在句尾。信息较密时拆分关系，信息连续时允许长句。
句间可以靠具体内容、必要关键词和指代承接，不必每句加连接词。“因此、然而、同样”等词必须对应真实关系；关系缺失时补足内容，不能仅换一个连接词。推导涉及实质判断时使用[LOGIC-02](reasoning.md#logic-02)。

<a id="prose-04"></a>
## PROSE-04 选择适合场合的语域

称谓、措辞、距离与态度要适合表达者、读者和场合。正式文字可以直接，亲切文字也需要内容清楚；口语表达要便于听懂和说出，不是在书面句尾添加语气词。
人称、情绪、礼貌和作者声音按功能使用。第一人称可能说明经验或解释归属，无人称也可能适合陈述；不按次数增删。需要建立声音、保持视角或转换语域时，加载[VOICE](voice.md)。

<a id="prose-05"></a>
## PROSE-05 用节奏承载内容

句长、停顿、段落和标点共同组织阅读节奏。连续动作、复杂解释、迟疑或强调需要不同速度，按内容调整，不以长短句比例判定自然。
简洁不能删掉必要关系；舒缓也不能靠同义复述填长。整齐、重复、碎片和跳切都可能有作用，只有遮蔽内容或破坏预期效果时才调整。不要为模拟真人故意制造错字、逻辑断裂或随机口语。

<a id="prose-06"></a>
## PROSE-06 让修辞产生具体效果

比喻、反问、排比、反复、对比等手段要服务理解、感受或记忆，不能代替事实和推理。比较双方应有可理解的关联，语气转折应有实际理由。
不预设每个判断都要补一个反面意见，每个段尾都要有金句。作者有意的锋芒、幽默、庄重和诗性可以保留；不把不同修辞全部清洗成中性说明。

<a id="prose-07"></a>
## PROSE-07 区分必要指引与空转播报

来源归属、篇章导航、作者解释和交际礼貌有时是必要内容。判断它们是否帮助读者辨认依据、位置、立场或关系，而非一概删除。
只宣告“这一点很重要、下面深入分析、体现了价值”，却没有说明实际内容时，应补清具体判断或删除。重复播报同一来源、复述标题、证明完成制作要求，没有增加阅读价值时不保留。替换“指出”为“强调”不能解决空转。“有个人思考”“联系现实”等写作要求通过实际判断和材料关系落实，不改写成“这引发了我的思考”“结合当下社会”的任务回声。确有作用的第一人称和过渡仍按内容保留。

<a id="prose-08"></a>
## PROSE-08 用实际作用选择保留或修改

检查一句话是否完成了信息、解释、叙述、情绪、审美或交际作用。删除后仍然通顺，不意味着没有损失：可能丢失归属、态度、节奏或礼貌。反之，只剩话题而没有内容时，应补真实内容或删掉无必要段落。
用户提出“机械、松散、不自然”等评价时，对照实际文字判断原因，不把举例当成已经发生的缺陷。诊断按实际作用与[任务目标](../core.md#core-01)定位；词频和固定句式统计只可能提供线索，不能直接决定质量。保留、补充和调整都应服务当前位置的作用；不要把“每句都有价值”执行成每句必须增加新事实或作出新判断，必要的铺垫、停顿和余韵按作品目的保留。
