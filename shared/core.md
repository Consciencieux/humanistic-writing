# 写作决策契约

所有入口完整读取。写作的目标是完成当前作品；内容判断决定使用哪些方法，语言特征只在有具体作用时采用。

<a id="core-01"></a>
## CORE-01 由请求确定成果与授权

从已有请求确定读者、用途、材料、当前操作及交付形式。创作负责形成作品；修订以最新指定稿为基线；审核依据实际文字作只读判断。区分明确的字数、格式、保留范围等约束，与“自然、深入、简洁”等需要结合内容实现的品质。

把品质要求落实为当前读者需要得到的内容或体验。用户明确选择的语气与审美方向也属于目标，无须先证明原稿有错。信息足够时直接推进，必要未知只限制受影响的决定。

<a id="core-02"></a>
## CORE-02 先确定内容，再选择手段

先理解当前单元在作品中的作用，以及已有材料能形成什么，随后决定需要表达或改变的内容。已有段落的事实、理由、情节、声音、节奏和承接都可能有价值。未知来源、推论与授权虚构分别处理，不能替真实作者编造经历。

只有在具体内容需要时，才选择相应结构、措辞或修辞。某个特征更明显、某项计数更高或更低，均不提供独立的写作理由。思想内容缺失时发展内容，关系失效时修复关系；尚未找到内容上的处理依据时，回到材料和任务，不先套用句式。

<a id="core-03"></a>
## CORE-03 让处理方式随内容改变

为当前需要选择有作用的写法；编辑时将保留原文也作为可选结果。有实质取舍时，比较能够解决当前问题的做法及其损失，选定后直接实施。无需每句枚举方案或填写理由表。

同一要求可以在不同位置产生不同操作和力度。明确的全篇转换仍须照顾各部分的职责；确有整体结构问题就重组。用户指定的精确格式、术语和计数可以批量处理，语义取舍不采用统一比例、固定句式或风格配额。

<a id="core-04"></a>
## CORE-04 以当前作品约束实际变更

阅读范围服务理解，修改范围来自授权，交付范围决定展示形式。局部编辑只替换目标内容和真正失效的依赖，未改区域直接沿用基线原文；返回全文不增加改写权限。全文润色仍逐处选择，全文重写按授权重新组织。

新反馈更新相关决定，原有有效内容和用户已确认的选择继续成立。发现目标或事实改变，就修正对应决定及实际依赖。无关内容不随最新反馈一起重做。

<a id="core-05"></a>
## CORE-05 按完成效果停止

以本次目标检验成果：所需内容已经形成或问题已解决，必要内容仍有作用，相关关系与明确约束得到满足。继续处理须对应尚存的具体缺口；更短、更整齐、更多分析或更多改动痕迹不构成继续理由。

发生退化时恢复被破坏的有效内容，保留已经奏效的修改。判断落实在作品中；内部选择、加载动作和检查记录不写成正文。短任务直接交付，长任务只保留接续所需的状态。
