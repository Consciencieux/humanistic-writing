# 设计依据

## 为什么从决策关系治理

“自然、有思考、深入、简洁”给出期望品质，具体写法取决于材料、用途和当前位置。一个段落缺少支撑，另一个段落可能已经充分；两者收到同一句反馈，应产生不同的编辑动作。

核心契约把操作的依据放在实际内容上。Guide 需要形成选定的内容与变化，然后调用具体能力；Audit 根据稿件中的作用和损失裁决。新增方法和禁令都沿这个关系发展，不能通过语言配额、默认比例或越来越长的检查表取代判断。

## 正面写作与严格审查怎样协作

Guide 具有发展内容、安排表达和完成编辑的责任。实例说明选择如何成立：材料缺少理由时补理由，人物变化需要行动时写行动，层次拥挤时调整组织。实例不成为全文模板。

Audit 对确认的代理替代、越界修改、内容损失与机械误判采用绝对禁令。成立条件需要阅读实际语义；合理的对比、第一人称、反复、留白与明确结论可以继续使用。审核反馈指向具体损失和修复范围，Guide 保留主动选择写法的空间。

领域标准集中维护共同语义。入口提示当前责任，方法落实操作，禁令给出裁决条件。文件分工随真实职责改变，不为每种风格新增一个管理层。

## 为什么直接禁止与正面引导需要不同所有者

在一般说明、演讲稿和非虚构论述中，主动生成主持人串词、假互动、装饰性俏皮比喻、金句、装饰性引号与批量标题钩子，只是将“生动、口语、吸引人”代理化为文本标记。已确认属于这些行为就删除，不提供“少写一点”或“换个更高级的笑话”等替代方法。禁令位于 `shared/standards/prose.md` 与 `shared/standards/organization.md`，避免 Guide 和 Audit 对同一行为分别定义。用户素材中的原话仍由来源责任处理。

清晰度、内容深度、术语解释、数据呈现、口头汇报、学术表达和篇幅修订则属于真实写作能力：禁止失败行为还需要 Guide 的有效做法。例如，一个技术段落可能真正缺少指标含义，另一个可能只是专业但准确；对它们不能套用“减少术语”的同一动作。Guide 在 `explain.md`、`registers.md` 提供按场景选择材料、形成解释与调整语域的方法。Audit 对照实际缺口判断，修复意见要指出缺少的关系而非换一套风格标签。

反例素材用于辨认违规，不将装饰性幽默、主持人话术和金句作为正面示范；正面例子只展示事实解释、口头可听性、证据表达和作者判断。审核的禁令在其成立条件满足时绝对执行，不把词语黑名单当作事实判断。

## 相同反馈的不同选择

| 请求 | 材料差异 | 决策依据与处理 |
| --- | --- | --- |
| 缩短一些 | 同一会议时间地点反复出现 | 合并重复，保留必要行动信息 |
| 缩短一些 | 校验步骤、例外与人工处理挤成一段 | 拆开关系并收紧措辞，保留方案运行条件 |
| 有自己的思考 | 已有独立判断和充分理由 | 保留分析，处理真正不清楚的归属或关系 |
| 有自己的思考 | 只有观察和“很有启发” | 根据观察发展具体判断及依据 |
| 更自然 | 书面说明缺少对象与句间关系 | 还原对象和关系，按场合表达 |
| 更自然 | 对白中的停顿构成人物犹疑 | 保留停顿和人物声音 |

这些差异检验模型是否依据内容选择动作。大幅删改与原样保留都可能成立；结构确实失效且已授权时应重构。明确数字上限要求实际减字，不能只拆段后宣称满足。

## 从成熟分工继承什么

[academic-writing](https://github.com/Consciencieux/academic-writing) 的[架构](https://github.com/Consciencieux/academic-writing/blob/main/docs/architecture.md)、[成文方法](https://github.com/Consciencieux/academic-writing/blob/main/skills/academic-writing-guide/references/draft-and-revise.md)与[审查方法](https://github.com/Consciencieux/academic-writing/blob/main/skills/academic-writing-audit/references/review-methods.md)提供角色分离、方法与判定分工、完整读取和独立封装的参照。

本库使用通用写作的目标与语义：叙事、论述、实用交流和审美表达分别依据其作用选择方法。学术章节配方、统一字形要求和默认全篇审查不进入通用任务基线。

## 如何继续发展

先明确新经验影响哪一种内容决定，再修改其所有者。Guide 增补有效的选择方法，Audit 细化真实的违规条件，共享标准完善语义依据。每项经验都保留适用范围，不把一次局部纠正改成全文永久禁令。

行为案例从真实任务差异设计。相同要求配不同内容，常见形式配合法与失败用法，多轮修订使用上一轮实际稿件。判据看问题是否解决、作品作用是否保留，不奖励规则复述、找错数量或机械零命中。
