# 语域与表达场合

从读者、媒介、作者身份和作品目的决定表达方式。根据[声音标准](../../../shared/standards/voice.md)和[语言标准](../../../shared/standards/prose.md)处理；不同场合有不同的理解需求，不强制全篇使用同一种句法表面特征。

<a id="register-01"></a>
## REGISTER-01 面向现场听众的讲稿

以听众单次聆听能够理解为目标，确定当前要解释的对象与先后关系。将密集的专业条件拆解到合适的位置，交代关键数据的口径，保留清楚的主题承接。通过句子结构、信息重点和停顿实现可听性；原本已经清楚的技术事实保持平实准确。

直接禁止主持人式假互动、俏皮段子、口语按钮和装饰性引号；按[PROSE-09](../../../shared/standards/prose.md#prose-09)至[PROSE-11](../../../shared/standards/prose.md#prose-11)执行。不要把这些被禁止的写法当作“活泼讲稿”的示范。

<a id="register-02"></a>
## REGISTER-02 学术论文与正式论述

通过研究对象、实际证据、定义、比较条件和判断强度建立严谨性。论述先呈现成立的发现，再在受影响处交代必要限制；有依据的结论直接说。按论文、课程报告、研究综述、政策说明等具体文种与用户模板调整材料和形式。优先让读者理解推理，专业术语在准确传达需要时使用。

示例材料：同一配置下进行了三次计时，方案 A 的耗时为 80、100、120 ms，方案 B 为 70、90、110 ms。可以写：

> 在相同测试配置下，方案 B 三次计时的中位耗时为 90 ms，方案 A 为 100 ms。方案 B 在这组三次测量中的中位耗时较低。

这里给出实际比较和适用条件；不要为了显得客观改成无主体的抽象表态，也无需在后面添加对无关场景的防御性否定。正式写作仍以[VOICE-07](../../../shared/standards/voice.md#voice-07)和[LOGIC-03](../../../shared/standards/reasoning.md#logic-03)为准。

<a id="register-03"></a>
## REGISTER-03 个人思考、文本回应与观点表达

适用于读书笔记、评论、思想体会、复盘与随笔等以“个人判断和认识变化”为核心的作品。不以“读完后我深受启发”“结合当下社会”等任务回声起手，也不代真实作者编造顿悟或经历；按三项正面动作展开：
1. **从具体抓手长出问题**：先锚定原文本的某处矛盾、数据反常或亲历事实，再提出作者真正要追问的区别。
2. **用依据支撑立场变化**：写清是什么材料或观察让看法发生了推进，保留判断成立的条件。
3. **允许保留真实分歧**：材料尚不足以定论时，直接说明未解之处与卡点，不强行凑出圆满结论。

示例（材料：作者读完某篇讨论“简化操作流程后错误率上升”的复盘报告，发现报告把“省掉必填校验”算进了流程简化）：
> 报告把省掉必填校验算进了流程简化，错误率上升正是因为缺少校验。想降低错误，把校验补回来就行，不必恢复原来的全部审批。

<a id="register-04"></a>
## REGISTER-04 同一作品中的语域协同

技术事实、解释、评论和叙事可以有不同的重心，但转场应由内容之间的真实关系引起。遇到严肃数据就清楚解释它，遇到确需展开的争议就展开理由；不按固定周期在专业术语和网络口语之间切换。保持稳定的表达者身份与读者距离，不因最新的“更生动”反馈对全文喷涂一种声音。

<a id="register-05"></a>
## REGISTER-05 叙事与场景表达

适用于人物故事、非虚构特写、散文与虚构场景。核心责任是让事件、动作和信息差自己说话，而不是由作者站在旁白席替读者总结意义：
1. **用动作与细节替代情绪标签**：不直接写“他很委屈”“气氛十分尴尬”，改写具体动作、视线转移、停顿或对话里的回避。
2. **守住当前视角的信息差**：只写该视角在此时此地能看到、听到、知道的事，不提前剧透全局动机或心理结论。
3. **保留有作用的克制心理描写**：人物内心的真实犹豫或误解可以写，但服务于后续行动或悬念，不在段末点破道理。

示例（场景：父亲来城里看刚工作的女儿，临走前看到门口鞋柜里全是开胶的旧鞋）：
> 父亲蹲在门口把那双开胶的运动鞋摆正，起身时把两百块钱压在桌上的茶杯底下，只说了一句“下楼赶车了”。

<a id="register-06"></a>
## REGISTER-06 实用交际与行动沟通

适用于通知、工作邮件、协同说明与操作指南。核心责任是让读者用最少阅读成本确认状态和下一步行动：
1. **结论与行动前置**：第一句直接交代发生了什么、需要对方做什么或决策边界在哪里。
2. **条件与例外紧随其后**：把截止时间、适用对象、例外处理入口集中交代清楚，不埋在长段末尾。
3. **礼貌靠准确与克制实现**：使用得体称谓和简洁致谢即可，不堆砌“感谢您的理解与支持，祝您工作顺利”等空洞套话。

示例（材料：周四下午 3 点服务器升级，预计中断 20 分钟，异常联系值班运维）：
> 各位同事：本周四 15:00–15:20 将进行服务器升级，期间系统暂停访问。如升级后出现异常，请联系值班运维处理。
