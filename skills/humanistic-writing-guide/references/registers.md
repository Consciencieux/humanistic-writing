# 语域与表达场合

从读者、媒介、作者身份和作品目的决定表达方式。根据[声音标准](../../../shared/standards/voice.md)和[语言标准](../../../shared/standards/prose.md)处理；不同场合有不同的理解需求，不强制全篇使用同一种句法表面特征。

<a id="register-01"></a>
## REGISTER-01 面向现场听众的讲稿

以听众单次聆听能够理解为目标，确定当前要解释的对象与先后关系。将密集的专业条件拆解到合适的位置，交代关键数据的口径，保留清楚的主题承接。通过句子结构、信息重点和停顿实现可听性；原本已经清楚的技术事实保持平实准确。

直接禁止主持人式假互动、俏皮段子、口语按钮和装饰性引号；按[PROSE-09](../../../shared/standards/prose.md#prose-09)至[PROSE-11](../../../shared/standards/prose.md#prose-11)执行。不要把这些被禁止的写法当作“活泼讲稿”的示范。

<a id="register-02"></a>
## REGISTER-02 学术论文与正式论述

通过研究对象、实际证据、定义、比较条件和判断强度建立严谨性。论述先呈现成立的发现，再在受影响处交代必要限制；有依据的结论直接说。按论文、课程报告、研究综述、政策说明等具体文种与用户模板调整材料和形式。优先让读者理解推理，专业术语在准确传达需要时使用。

示例材料：同一配置下进行了三次计时，方案 A 的耗时为 80、100、120 ms，方案 B 为 70、90、110 ms。可以写：

> 在相同测试配置下，方案 B 三次计时的中位耗时为 90 ms，方案 A 为 100 ms。方案 B 在这组三次测量中的中位耗时较低。

这里给出实际比较和适用条件；不要为了显得客观改成无主体的抽象表态，也无需在后面添加对无关场景的防御性否定。正式写作仍以[VOICE-07](../../../shared/standards/voice.md#voice-07)和[LOGIC-03](../../../shared/standards/reasoning.md#logic-03)为准。

<a id="register-03"></a>
## REGISTER-03 个人观点与非虚构的作者声音

作者已经明确提出的问题、怀疑、经历和立场可直接进入作品。自己的思考通过对材料作出解释、指出真实区别、分析其理由或保留具体未解问题呈现；不需要每段先说“我认为”或叙述一段虚构顿悟。

原稿有实际个人表达时保留其归属与声音。用户只提供了主题没有提供自身经历时，可以形成有依据的分析，但不能冒充作者补写传记式细节。读书笔记、评论与叙事性非虚构的语言选择按作品用途决定，不一律改成学术报告，也不刻意口语化。

<a id="register-04"></a>
## REGISTER-04 同一作品中的语域协同

技术事实、解释、评论和叙事可以有不同的重心，但转场应由内容之间的真实关系引起。遇到严肃数据就清楚解释它，遇到确需展开的争议就展开理由；不按固定周期在专业术语和网络口语之间切换。保持稳定的表达者身份与读者距离，不因最新的“更生动”反馈对全文喷涂一种声音。
