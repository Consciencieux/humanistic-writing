# 翻译、提炼与转换

翻译、总结、整理原话或改变受众、媒介和语域时完整读取，并读取[修订方法](revise.md)。先确定新用途及允许的取舍，再生成转换结果。

<a id="xform-01"></a>
## XFORM-01 翻译意义与表达作用

保留事实、条件、立场、语气和交际关系，按目标语言的习惯重新成句。术语一致，人物与来源归属清楚，不为显得丰富更换必要指称。
原文的含混、礼貌或讽刺有作用时，在目标语言中实现相应效果。原文未提供的信息不补成事实；歧义影响结果时处理具体位置，不把译文变成额外讲解。

<a id="xform-02"></a>
## XFORM-02 总结和提炼

按所需层次保留中心内容及其重要条件。可以改变组织顺序，但不能把疑问改成定论、个人体验写成群体事实，或因压缩删掉决定结论的限制。
只总结时不添加评论；授权评论时区分新增解释。出处、观点和人物层次按实际材料保留。总结允许按目的舍弃展开；润色或“缩短一些”仍依[EDIT-04](revise.md#edit-04)保留有效内容，不默认转成摘要。

<a id="xform-03"></a>
## XFORM-03 调整受众、媒介与语域

根据读者的已有知识、阅读场合和所需行动，调整解释分量、措辞、距离及组织形式。转为口头表达要让听众能够跟随，正式化要符合场合，通俗化要帮助理解。
转换不默认授权改变事实、承诺、立场或叙事事件。全篇可以有统一方向，各段仍按实际功能采用不同手段。具体声音判断见[VOICE-05](../../../shared/standards/voice.md#voice-05)。

<a id="xform-04"></a>
## XFORM-04 整理零散材料与转写

消除影响阅读的口头填充、识别错误和无作用重复，保留有意义的犹疑、强调、改口及思想联系。不能把连贯的推演整理成无关联主题清单。
材料缺字或含义不明时回原材料确认，无法确认不编造发言。授权从素材发展成作品时可以补必要衔接与解释，但不代编真实人物的经历。
