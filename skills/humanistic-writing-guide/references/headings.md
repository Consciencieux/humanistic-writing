# 文章标题与小标题

拟题、改题、制作目录或修改章节名称时读取[组织标准](../../../shared/standards/organization.md)，按其中的内容命名、长度提示和完整禁令执行。本方法提供正面的命名动作；不为幽默、金句、装饰性引号或标题钩子提供生成示例。

<a id="heading-01"></a>
## HEADING-01 取得标题对应的内容

主标题读取全文重心及必要正文，小标题读取本节、上级标题与相邻章节。提纲阶段使用已确定的内容安排形成暂定名称，成文后再与真实内容对应；不能用一个空主题推定整节的论点。用户只要求标题时，只修改标题及获准联动的目录和回指，正文继续作为依据。

先用普通语言弄清这部分完成了什么。例如，一节比较人工检查与自动检测的适用条件，核心是两种检查方式的比较；其中出现的设备、费用和操作步骤用于支撑比较。标题据此选择主要对象及关系，细节留在正文。

<a id="heading-02"></a>
## HEADING-02 提炼名称并作必要取舍

从实际内容中选定最主要的对象、过程、事件、问题或判断，再采用正常汉语为它命名。优先考虑已经准确成立的普通名称。专业词、必要对象和决定含义的关系保留；作者的讲解动作、次要关键词、态度修饰和正文已有的解释不进入标题。

上级标题明确背景时，下级名称可以直接写“车辆兼容性”“燃烧仿真”“质量追溯”。如果本节比较两种做法，就写出比较对象；如果本节解释一种关系，就标识该关系。关键词是理解材料的线索，不能把最显眼的几个词直接拼成标题。

形成一个准确名称后，不再追加概念列表或另一句概括。普通标题完成导航即可；不为了避免常见表达而重新发明短语。

<a id="heading-03"></a>
## HEADING-03 按文章用途命名

说明、汇报和技术文档的题名直接标识对象和主题；下级标题标识本节的过程、方法、现状或问题。读书笔记保留作者真正提出的问题及所读作品的身份，不把每节都改成感想宣告。评论的判断型标题需要正文已经形成的理由；叙事作品按人物、事件、场景或主题取名，维护用户选定的声音。

主标题须覆盖全文真正的重心。副标题在读者需要辨认作品、范围或文种时补充这一项信息，不把几个次要议题全搬进去。常规小标题的 4–12、13–18 字参考按[ORG-06](../../../shared/standards/organization.md#org-06)使用；主标题不套用这组参考，固定格式照实际要求处理。

<a id="heading-04"></a>
## HEADING-04 由具体内容形成标题

以下为合成教学材料，标题只适用于表中给定内容，不是供全文轮换的句式库。

| 已确定的内容 | 可用标题 | 取舍依据 |
| --- | --- | --- |
| 全文介绍乙醇汽油性质与使用问题，计算机应用只占一节 | 乙醇汽油的性质与使用 | 主标题覆盖全文；不把局部专业视角扩大为总主题 |
| 本节解释燃料热值差异和实际油耗的关系 | 燃料热值与汽车油耗 | 保留两个主要对象及关系；工况和实验明细在正文展开 |
| 上级标题已明确讨论乙醇汽油，本节只讨论旧车型的燃料系统适配 | 车辆兼容性 | 背景由上级提供；本节名称能直接定位 |
| 本节说明利用计算机仿真比较不同发动机参数设置 | 发动机参数的仿真筛选 | 明确筛选对象与采用的方法，不把被动动作压成别扭句子 |
| 本节只有燃烧数值计算、模型设置与结果解释 | 燃烧仿真 | 不根据全文中的其他技术术语扩大本节范围 |
| 本节记录批次编号、检验记录与出库去向的关联，用于查找问题批次 | 燃料质量追溯 | 用实际用途统摄相关记录，不在题后逐项列名 |
| 操作指南的一节实际回答旧型号能否安装新版，列出型号条件与处理方法 | 旧型号能否安装新版？ | 问题确实是读者的检索入口，有具体对象与回答 |
| 读书笔记围绕“生产力的发展最终使谁受益”展开，并以《共产党宣言》为阅读对象 | 生产力的发展，最终将使谁受益？——《共产党宣言》读书笔记 | 主标题来自真实阅读问题，副标题仅交代作品与文种 |

标题是否自然也要看搭配和语序。“参数筛选”“兼容性”“质量追溯”都有明确含义；不要为显得口语化改成“参数在仿真中筛选”“应用中要注意什么”或“全链条里其实也有信息”。正文实际只讨论某一技术时，就选它的正常名称。

<a id="heading-05"></a>
## HEADING-05 核对对应关系并结束

将拟定标题放回目录与正文。确认主标题没有偏离全文，小标题能区分兄弟小节，上下级范围相容，汉语搭配自然。出现过长、多个并列词或抽象概括时，只检查这些成分是否真正决定定位，不按字数或符号直接删改。

审核指出标题有问题时，从对应内容重新命名；不能只删除冒号、换掉疑问词或换一组关键词。准确的原标题保留，平行命名有内容依据时保留。发现本节没有重心且超出改题权限时说明结构问题，不为适配新标题添加正文。命名与导航已经完成就交付，不再为独特、整齐或吸引力继续加工。
