# 构思、起草与续写

创作从作品需要出发，形成可用内容，再进入句段表达。执行[决策契约](../../../shared/core.md)，以下方法用于实际选择。

<a id="write-01"></a>
## WRITE-01 找到值得写的内容

读取任务材料，确定读者要理解的关系、经历的变化、感受到的情境或完成的行动。已有思想链就继续展开；授权原创时主动选择角度、素材或情节。构思用[内容标准](../../../shared/standards/content.md)，多段安排用[组织标准](../../../shared/standards/organization.md)。

“有思考”落实为值得表达的判断，“自然”落实为适合对象与场合的表达，“深入”落实为当前尚需展开的关系。这些选择应在材料中有落点。没有原稿时直接形成内容，不把等待用户提供所有观点作为默认做法。

<a id="write-02"></a>
## WRITE-02 发展所选内容与关系

判断需要理由就展开理由；行动引起人物变化就写清相关行动与反应；实用文字围绕读者要做的事组织。决定哪些材料参与表达、如何连接，以及在哪个位置主要展开。依据[推理](../../../shared/standards/reasoning.md)、[声音](../../../shared/standards/voice.md)和[来源](../../../shared/standards/sources.md)处理实际涉及的关系。

例如材料是“自由发言后讨论时间增加，发言人数未变，两人反映找不到加入机会”。值得展开的是时长与参与机会的区别，以及反馈怎样支持改进方向。分析完成后直接表达该判断。若另一份材料已把这个区别和理由讲清，保留它，继续处理剩余内容。

文学创作可通过情境、行动、意象和节奏形成意义。给每段配齐事实、解释与总结会破坏这种安排；按当前作品需要选择发展方式。

<a id="write-03"></a>
## WRITE-03 把意思写成当前作品的语言

内容及其关系明确后，读取[语言标准](../../../shared/standards/prose.md)，按照读者的理解顺序连续成文。选择句法、详略、停顿与修辞，使需要的意思、声音和体验能够发生。不同作用的段落可以采用不同表达。

续写读取连接位置和必要前文，沿用已成立的事实、视角与关系，从尚未完成的内容继续。写作中发现材料无法支撑原安排，就调整内容选择，不用过渡和总结填补空位。

<a id="write-04"></a>
## WRITE-04 读回作品并完成

按原任务读回本次单元：读者是否已得到所需内容，关系是否成立，明确的事实、格式和篇幅条件是否满足。发现具体缺口就修复；内容已完成其作用时收束。

交付作品本身。内部选材、加载和判断过程留在工作上下文；用户没有要求时，不附逐项自评或另一版全文。需要编辑已有部分时转入[修订方法](revise.md)，保持其基线与授权。
