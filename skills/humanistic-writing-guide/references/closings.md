# 开篇、段落过渡与结尾收束

起草或修订完整篇章的开头、段间推进与结尾时，配合[组织标准](../../../shared/standards/organization.md#org-03)与[推理标准](../../../shared/standards/reasoning.md#logic-05)使用。

<a id="closing-01"></a>
## CLOSING-01 判断收束是否已经成立

写到最后部分时，对照全文目的看两件事：
1. **如果前文已经把读者需要知道的结果、行动或情绪落点交代完整**：只需顺势收口或保留得体礼貌让语气落下来，不要再另起一段把前文要点换词重说一遍。
2. **如果前文只是列完局部事实、分论点或单个场景，读者还不知道这整件事最终落向哪里**：补上当前作品缺少的收束，不要在最后一个局部细节写完后直接断电。

<a id="closing-02"></a>
## CLOSING-02 按作品需要选择收束落点

依据文章最后还缺什么作用选择收束方式，允许在同一结尾自然结合，不把文体和写法死锁：
* **交代具体去向或后续安排**：把前面确立的判断落回实际执行、后续条件或前文已暴露的真实卡点。
* **保留得体的交际收口**：通知、致歉、书信等实用文本保留真诚、简短的致谢或致歉，不把正常人情味当成废话删光，只去掉虚假的广告式煽情。
* **作实质综合**：长篇分析或学术讨论在结尾把前文分散的几部分关系收拢到核心判断，不为了“避免总结”硬生生把文章砍断。
* **自然停在场景或情绪上**：叙事文本停在人物真实反应、对话或具体场景上，不在最后一句跳出视角充当旁白点破人生道理。

<a id="closing-03"></a>
## CLOSING-03 结尾禁令的识别与防误伤边界

执行[ORG-03](../../../shared/standards/organization.md#org-03)的结尾约束时，重点识别四类脱离正文的写法：莫名反问与伪开放追问、突然引入全文未讨论过的新议题、换词复述前文要点的同义总结，以及空洞口号或强行宏大升华。

同时守住三项防误伤边界：
* 不因结尾出现问号，就把前文已铺垫的真实未决问题或叙事悬念机械判错。
* 不把长文或学术讨论必需的实质综合，误删成“禁止总结”。
* 不把实用通知与书信中真诚克制的致歉、感谢，误删成“多余废话”。

<a id="closing-04"></a>
## CLOSING-04 开篇切入与段间推进

开篇围绕读者当前的理解需要决定从哪里进入：读者已经熟悉背景时，直接进入核心事件、判断或矛盾；陌生读者缺少前提时，用简短篇幅交代必要基准，不铺陈“随着……的发展”等空泛大背景。

段与段之间靠内容的先后推进自然连接（比如从现象到原因、从具体材料到判断、或随时间与视角移动），不用“接下来我们再看”等过程播报硬切。发现两段之间发飘或跳跃时，先检查是不是段落顺序颠倒、中间少了一步交代，或者两段其实在重复同一件事。
