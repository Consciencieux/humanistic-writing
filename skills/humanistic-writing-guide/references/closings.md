# 开头与结尾段写作

起草、续写或修订文章的开篇与收束时读取[组织标准](../../../shared/standards/organization.md#org-03)与[推理标准](../../../shared/standards/reasoning.md#logic-05)。本方法提供正面的切入与着陆动作，解决“开头宏大铺垫”“结尾莫名反问、生造新问题、同义总结或戛然而止”的问题。

<a id="closing-01"></a>
## CLOSING-01 先判断作品是否已经自然停住

收尾前先读前文最后两段，辨认两类状态：
1. **已有完整落点**：前文最后一段已经给出了核心判断、适用边界、人物最终动作或读者可执行事项。此时**不需要单设结尾段**，补齐必要条件后直接停笔。
2. **尚缺收束动作**：前文只是逐项列完分论点、事实或步骤，停在局部细节上，读者不知道全文要落到哪里。此时才补写结尾，负责把分散内容收拢到当前作品的终点。

不得为了凑“总—分—总”结构，在已经落地的文章末尾硬加一段“综上所述”。

<a id="closing-02"></a>
## CLOSING-02 按文体与用途选择正面着陆动作

依据作品目的选定一种收束方式，不跨文体混用：

| 作品类型 | 正面着陆动作 | 典型落点 |
| --- | --- | --- |
| **实用通知 / 操作指南** | 停在读者下一步行动、办理入口或生效边界 | 办理方式、截止时间、例外处理渠道 |
| **分析汇报 / 技术说明** | 停在核心判断的适用范围、决策取舍或尚未测量的具体卡点 | 当前能支持的结论边界与待补数据 |
| **观点评论 / 读书笔记** | 回到开篇提出的具体问题，给出当前立足材料的回答或明确保留的分歧 | 对核心问题的最终判断，不另起新议题 |
| **叙事 / 文学场景** | 停在人物的一个具体动作、视线转移、对话停顿或状态变化 | 让场景自行留白，不在末句解释道理或情绪 |

<a id="closing-03"></a>
## CLOSING-03 结尾段禁令与正反对照

常规写作严格避免以下 5 种模板化结尾：
1. **严禁莫名反问与伪追问**：禁止用“难道不值得我们深思吗？”“未来又将何去何从？”“你准备好迎接变化了吗？”收尾。
2. **严禁在尾段引入新问题或新变量**：全文未讨论的概念、对策或宏观背景不得在最后一段突然出现；确需交代未解问题时，必须是前文论证中已经暴露出的具体卡点。
3. **严禁同义总结**：禁止把前文小标题或分论点换一套形容词再复述一遍（如“总而言之，A 很重要，B 也不可或缺，只有两者结合才能……”）。
4. **严禁强行拔高与祈使倡议**：非动员演讲、非倡议书场景，禁止用“让我们携手……”“这不仅关乎技术，更关乎人类未来”收尾。
5. **严禁无边界的戛然而止**：最后一条并列项或局部数据写完后直接停笔，既未交代比较结果，也未说明下一步怎么用，须补出与全文目的匹配的落点。

以下为合成教学示例，说明不同上文终点如何正面着陆：

| 上文终点与文体 | 常见坏结尾（避免） | 合格着陆（正面动作） |
| --- | --- | --- |
| 展厅维修通知：已说明今日闭馆及服务台原路退款 | 感谢您的理解与支持，让我们共同期待下一次更美好的相遇！ | 恢复开放时间确定后将在入口及官网另行公告；如需改期预约，可现场登记或致电服务台。 |
| 服务窗口效率分析：已说明办件量上升但未测等待时间 | 由此可见，窗口改革成效显著。那么，如何进一步提升群众满意度，仍值得我们深入思考。 | 现有记录只能确认同一时段办件量有所上升；若要判断排队等待是否缩短，仍需补充到厅至叫号的耗时统计。 |
| 深夜车站叙事：两人争吵因旧友递来一颗糖而停下 | 就这样，他们冰释前嫌。原来真正的友情，从来不需要太多言语。 | 他剥开糖纸把糖放进嘴里，没再往下说。站台广播响起时，两人各自拎起包往检票口走。 |

<a id="closing-04"></a>
## CLOSING-04 开头切入与无连接词承接

开头与结尾呼应，但开篇不先做背景铺垫。按任务选择切入动作：
* **实用与汇报类**：第一句直接给出对象、状态或结论（如“今日因设备检修暂停开放”或“在相同配置下，方案 B 的中位耗时比方案 A 低 10 ms”）。
* **解释与评论类**：从读者已有的常识起点与实际反常之间的缺口切入，不写“随着……的快速发展”“在当今社会”。
* **叙事类**：直接从具体时间、地点的人物动作或对话进入，人物背景在后续行动中按需要带出。

句段之间去掉“因此、然而、此外、总而言之”等机械连接词后，改用三种正面承接保持连贯：
1. **尾头相衔**：把上一句结尾引入的新对象或新条件，直接作为下一句开头的主语或话题。
2. **动作与后果直连**：前句写限制或动作，后句直接写该限制下发生的具体结果，省去“所以/由此可见”。
3. **局部指代回指**：用“这一差异”“上述条件”“该做法”精准回指前句对象，替代空泛的“这”“这一点”。
