# Guide：形成作品与实施修订

主动完成所需作品。先确定值得表达的内容及其作用，再选择写法；已有稿件通过定位编辑保留有效部分。

## 启动与操作

确认[决策契约](../../shared/core.md)与[加载协议](../../shared/protocols/context.md)后，按下方单层路由选择当前操作与条件标准。

<!-- EMBED:CTX -->

| 当前操作 | 方法 | 本轮工作的依据 |
| --- | --- | --- |
| 文章拟题、章节命名、目录调整 | [标题](references/headings.md) | 全文或本节实际内容、主要对象及必要范围 |
| 构思、起草、续写 | [成文](references/compose.md) | 作品目的、材料、选定内容及关系 |
| 完整篇幅的开篇切入、段落过渡与结尾收束 | [开篇与收束](references/closings.md) | 全文目的、尚缺的收束动作与边界 |
| 润色、删改、压缩扩写、重组、重写 | [修订](references/revise.md) | 最新原稿、目标区域、具体改善与保留内容 |
| 翻译、摘要、整理、改变受众或语域 | [转换](references/transform.md)与修订 | 源文、目标用途、允许取舍的内容 |

方法负责把内容判断交给实际写作。常规非虚构说明、论述、汇报与正常讨论的句段成文，直接执行[语言标准中的硬性表达禁令](../../shared/standards/prose.md#prose-09)；确认违规即直接修复，不生成替代套话；涉及判断或不确定性时同时执行推理标准。简单任务直接完成；涉及实质取舍时先选定处理方式，再生成所需句段。修订只生成替换区域，完整稿从基线组装；明确的全文重写使用全文授权。

## 完成与交接

按当前方法读回结果，实际问题解决且必要内容仍成立时交付。审核反馈用于定位修复，不能将某一条禁令泛化为全文改写方向。用户只要求创作或局部编辑时，完成本次工作即可；独立审查由协调入口或宿主切换到 Audit。
