# 根因治理禁令

本文件维护可裁决的失败行为；判断对象与完成条件由[决策契约](../../../shared/core.md)定义。以下禁令在成立条件满足时必须执行。按[审核方法](review.md)读取具体上下文，不依据表面命中作结论。

<a id="audit-01"></a>
## AUDIT-01 严禁以代理指标替代作品目标

禁止用词频、人称密度、句段长度、固定骨架、术语数量或改动量代替对内容与效果的判断。确认依据是：处理仅强化了这些特征，所需判断、关系、体验或用途仍未形成，或已有作用受到损害。

修复应回到尚未完成的内容，重选写法。用户明确规定的字数、格式、术语及风格选择按授权执行；须检查它们是否得到正确落实，不能把明确约束误报为代理指标。

<a id="audit-02"></a>
## AUDIT-02 严禁无内容依据地泛化操作或扩大权限

禁止把局部反馈转换为全文同质化处理，禁止将相同要求作为各处采用同一动作与力度的理由。版本与请求显示无关区域被改写，或不同内容受到同一处理而失去功能时，须纠正。

撤销无关改动，按内容差异处理目标位置。真实依赖可在授权内联动；已授权的全篇重写、语域转换及精确格式统一按各自范围执行。审核时必须核实授权，不能按改动比例定性。

<a id="audit-03"></a>
## AUDIT-03 严禁用一种改善交换未经授权的内容损失

禁止在润色、压缩或风格调整中，删除仍有作用的事实、条件、依据、情节、声音或表达归属；禁止把作者未决问题改成定论，或虚构真实作者的经历来表现思想与个性。核对源稿及语义关系，具体指出损失或新增的无依据内容。

恢复受损部分并保留有效修改。明确的摘要与用途转换允许相应取舍，授权虚构允许创造情节；仍须满足当前任务的事实、内容与归属责任。

<a id="audit-04"></a>
## AUDIT-04 严禁以形式变化冒充完成或继续无目标加工

所指问题尚在时，禁止以字数降低、语气变强或句式变多宣告完成。问题已解决时，禁止继续追逐同一特征直至损坏作品。发现实际缺口应继续完成，发现退化应恢复有效内容并停止无益操作。

根据任务、稿件和实际变化确认，不凭输出长短推断加工过程；不设置“修改越少越好”或固定轮数的替代目标。

<a id="audit-05"></a>
## AUDIT-05 严禁机械审核和无依据的违规判定

禁止因关键词、否定句、工整结构、第一人称或静态扫描命中就判错，禁止把用户标签直接当作故障事实。禁止以无问题可报为由制造问题，或将可选审美替代写成强制违规。

确认问题必须有实际位置、适用条件和影响。保留有作用的推理、修辞、铺垫与停顿；未读材料不得声称已核实。只有成稿时描述成稿缺陷，不编造其生成过程。审查自身同样遵守只读权限与完成边界。

<a id="audit-06"></a>
## AUDIT-06 严禁普通文本中违反直接语言禁令的写法

常规非虚构文本的直接语言禁令以[语言标准](../../../shared/standards/prose.md)为唯一权威定义，标题禁令以[ORG-08](../../../shared/standards/titles.md#org-08)为唯一权威定义。Audit 确认上述行为成立时必须标为需要修复，不得降格为可选风格偏好。

定位违规句段与实际影响，要求删去无作用内容或补足被遮挡的事实、判断与解释。按 AUDIT-05 排除误报，遵守材料性质和编辑授权。

<a id="audit-07"></a>
## AUDIT-07 严禁用格式完整代替内容与交流功能

对“结构完整但空洞”“数据和术语很多但难以理解”“专业与口语机械切换”“观点只呈现态度没有依据”等问题，按照[CONTENT-06](../../../shared/standards/content.md#content-06)、[CONTENT-07](../../../shared/standards/content.md#content-07)、[ORG-07](../../../shared/standards/organization.md#org-07)和[VOICE-06](../../../shared/standards/voice.md#voice-06)核对实际缺失的内容关系。

只有确认正文原本需要这些关系、且它们确实缺失，才作违规判定。修复方向指向应补充或重组的对象、前提、证据与说明，不以“术语减少一半”“多加两个例子”“每段都展开”替代判断。不得为了消除密度问题而删掉真实有效的技术内容。

<a id="audit-08"></a>
## AUDIT-08 严禁标题包装取代内容命名

完整加载[标题标准](../../../shared/standards/titles.md)并依据[ORG-06](../../../shared/standards/titles.md#org-06)与[ORG-08](../../../shared/standards/titles.md#org-08)全部条款裁决，不得只检查本轮最近提到的一类。

主标题对照全文重心，小标题对照本节、上级标题和必要的相邻内容。确认具体违规即要求修复，处理方向指向应命名的对象及关系。不得按标点、疑问词、字符数、标题相似度直接判错，也不得要求用户在原标题没有问题时换成另一种同样有效的表达。只收到题目而没有内容时，可判断明确的语言问题，内容对应关系保留待核实。

<a id="audit-09"></a>
## AUDIT-09 依据正文落点裁决结尾缺陷

对照[ORG-03](../../../shared/standards/organization.md#org-03)与[LOGIC-05](../../../shared/standards/reasoning.md#logic-05)，核查结尾段是否完成全文所需的收束动作，以及是否违背结尾禁令。

审查须指明尾段与前文断层、无依据引入新议题或同义空转的具体句段，修复方向指向应补出的落点或删去多余尾段；不得将前文已铺垫的真实未决问题、学术论文所需的综合概括或有效叙事余韵误判为违规。

<a id="audit-10"></a>
## AUDIT-10 裁决任务异化、虚构前提与判断漂移

依据决策契约与推理标准，确认虚构用户立场、无关证明义务、任务异化或无依据的判断漂移时，指出请求、材料与实际判断的差异并要求修复。依据可见文字和版本裁决，不从单稿推测谄媚动机；新证据或授权改变所支持的修正不判错。

<a id="audit-11"></a>
## AUDIT-11 双向裁决判断强度与内容价值损失

按[推理标准](../../../shared/standards/reasoning.md)同时检查结论夸大、弱化和遗漏，及强迫平衡、重复或分类对关键判断的遮蔽。指出能成立的判断、真实边界及需恢复的关系，必要时按重要性重组。材料不足仅标明实际缺口，不编造答案或擅改作者立场。
