# 根因治理禁令

本文件维护可裁决的失败行为；判断对象与完成条件由[决策契约](../../../shared/core.md)定义。以下禁令在成立条件满足时必须执行。按[审核方法](review.md)读取具体上下文，不依据表面命中作结论。

<a id="audit-01"></a>
## AUDIT-01 严禁以代理指标替代作品目标

禁止用词频、人称密度、句段长度、固定骨架、术语数量或改动量代替对内容与效果的判断。确认依据是：处理仅强化了这些特征，所需判断、关系、体验或用途仍未形成，或已有作用受到损害。

修复应回到尚未完成的内容，重选写法。用户明确规定的字数、格式、术语及风格选择按授权执行；须检查它们是否得到正确落实，不能把明确约束误报为代理指标。

<a id="audit-02"></a>
## AUDIT-02 严禁无内容依据地泛化操作或扩大权限

禁止把局部反馈转换为全文同质化处理，禁止将相同要求作为各处采用同一动作与力度的理由。版本与请求显示无关区域被改写，或不同内容受到同一处理而失去功能时，须纠正。

撤销无关改动，按内容差异处理目标位置。真实依赖可在授权内联动；已授权的全篇重写、语域转换及精确格式统一按各自范围执行。审核时必须核实授权，不能按改动比例定性。

<a id="audit-03"></a>
## AUDIT-03 严禁用一种改善交换未经授权的内容损失

禁止在润色、压缩或风格调整中，删除仍有作用的事实、条件、依据、情节、声音或表达归属；禁止把作者未决问题改成定论，或虚构真实作者的经历来表现思想与个性。核对源稿及语义关系，具体指出损失或新增的无依据内容。

恢复受损部分并保留有效修改。明确的摘要与用途转换允许相应取舍，授权虚构允许创造情节；仍须满足当前任务的事实、内容与归属责任。

<a id="audit-04"></a>
## AUDIT-04 严禁以形式变化冒充完成或继续无目标加工

所指问题尚在时，禁止以字数降低、语气变强或句式变多宣告完成。问题已解决时，禁止继续追逐同一特征直至损坏作品。发现实际缺口应继续完成，发现退化应恢复有效内容并停止无益操作。

根据任务、稿件和实际变化确认，不凭输出长短推断加工过程；不设置“修改越少越好”或固定轮数的替代目标。

<a id="audit-05"></a>
## AUDIT-05 严禁机械审核和无依据的违规判定

禁止因关键词、否定句、工整结构、第一人称或静态扫描命中就判错，禁止把用户标签直接当作故障事实。禁止以无问题可报为由制造问题，或将可选审美替代写成强制违规。

确认问题必须有实际位置、适用条件和影响。保留有作用的推理、修辞、铺垫与停顿；未读材料不得声称已核实。只有成稿时描述成稿缺陷，不编造其生成过程。审查自身同样遵守只读权限与完成边界。
